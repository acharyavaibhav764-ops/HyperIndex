# Version 0.3: Data Contracts & Typing

## Objective
Introduce strict, self-documenting Pydantic models for all API requests and responses. Eliminate raw `dict` return types, bind `response_model` to all endpoints, and unify identifier naming across the system.

---

## 1. Terminology & Identifier Standardization

### Problem in v0.1
The document identifier is referred to inconsistently:
- `/upload` response returns `"uuid": file_id`
- `/chunk-and-embed/{file_id}` uses `file_id`
- `README.md` and documentation refer to `document_id`

### Technical Specification
Standardize on **`document_id`** everywhere in schemas, route paths, and responses.

---

## 2. Dedicated Schemas (`schemas/`)

Organize Pydantic models under a `schemas/` directory:

### `schemas/document.py`
```python
from pydantic import BaseModel, Field

class DocumentUploadItem(BaseModel):
    document_id: str = Field(..., description="Unique document identifier")
    filename: str = Field(..., description="Original filename")
    size_bytes: int = Field(..., description="File size in bytes")

class DocumentUploadResponse(BaseModel):
    message: str
    count: int
    documents: list[DocumentUploadItem]

class ChunkItem(BaseModel):
    chunk_id: str
    text: str
    metadata: dict

class DocumentIndexResponse(BaseModel):
    document_id: str
    filename: str
    collection: str
    total_chunks: int
    indexed_chunks: int
```

### `schemas/query.py`
```python
from pydantic import BaseModel, Field

class QueryRequest(BaseModel):
    question: str = Field(..., min_length=1, description="Question for the RAG assistant")

class SourceItem(BaseModel):
    metadata: dict
    distance: float

class QueryResponse(BaseModel):
    question: str
    answer: str
    model: str
    sources: list[SourceItem]
```

### `schemas/health.py`
```python
from pydantic import BaseModel

class HealthResponse(BaseModel):
    status: str = "ok"
    version: str = "1.0.0"
```

## 3. Schema Enforcement on Endpoints

### Problem in v0.1
Route functions are typed as `async def ... -> dict:`. Swagger UI (`/docs`) cannot generate response schemas, and errors in payload keys go unnoticed.

### Technical Specification
Add `response_model` to route decorators and update return type annotations:

```python
@app.post("/upload", response_model=DocumentUploadResponse)
async def upload_files(files: list[UploadFile] = File(...)) -> DocumentUploadResponse:
    ...

@app.post("/chunk-and-embed/{document_id}", response_model=DocumentIndexResponse)
async def chunk_and_embed(document_id: str) -> DocumentIndexResponse:
    ...

@app.post("/generate", response_model=QueryResponse)
async def generate_answer(request: QueryRequest) -> QueryResponse:
    ...
```

## 4. Elimination of Debug Artifacts

### Problem in v0.1
In `/chunk-and-embed`, the response contains:
```python
response_chunks = [
    {"id": chunk_ids[i], "text": chunks[i], "metadata": metadatas[i]}
    for i in range(0, len(chunks), 10)
]
```
This was a prototype debug slice returning every 10th chunk.

### Technical Specification
Replace this with clean index summary metadata (`total_chunks`, `indexed_chunks`, `collection`), keeping response payloads fast, lean, and standard.
