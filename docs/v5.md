## Architecture Overview

v5 replaces `PdfStubParser` with `PdfPageRouter`. The key insight is that no single PDF parser is optimal for all pages:

```
Incoming (.pdf bytes)
        │
        ▼
   ParserRouter  (parsers/router.py)
        │  dispatches by extension
        ▼
PdfPageRouter  (parsers/pdf_router.py)  ← NEW IN v5
        │
        ├─ 1. Open PDF with PyMuPDF (fitz)
        │
        ├─ 2. For each page → _triage_page(page)
        │         │
        │         ├─ flags = {text_ratio, has_table, has_image}
        │         │
        │         ├─ if text_ratio HIGH, no table, no image
        │         │       → PyMuPDF4LLM  (fast markdown extraction)
        │         │
        │         ├─ if has_table
        │         │       → Docling  (structural table extraction)
        │         │
        │         └─ if has_image (or low text ratio)
        │                 → SmolVLM  (via Docling VLM pipeline / direct inference)
        │
        ├─ 3. Collect page-level results (markdown strings / DoclingDocuments)
        │
        └─ 4. Assemble into a single DoclingDocument via _merge_pages()
                │
                ▼
        DoclingDocument
                │
                ▼
        HybridChunker → TextChunk[]
```

**Triage logic (heuristics, tunable via config):**
- **Text ratio** = `(len(page.get_text()) / page.rect.width * page.rect.height)` — if above threshold (`PDF_TEXT_RATIO_THRESHOLD`, default `0.05`), the page is considered text-heavy.
- **Table detection** = `len(page.find_tables().tables) > 0` (PyMuPDF built-in table finder).
- **Image detection** = `len(page.get_images()) > 0`.

Three new settings are added:

## Phase 2: `PdfPageRouter` Implementation

### What is happening
Create `parsers/pdf_router.py`. This is the core of v5.

The class inherits `BaseParser` (from `parsers/base.py`) and claims `.pdf` extension — exactly as `PdfStubParser` does. When registered in `router.py`, it will supersede `PdfStubParser`.

**Triage method** `_triage_page(page)` inspects a single `fitz.Page` and returns one of three routing tokens: `"text"`, `"table"`, or `"image"`.

**Parse method** opens the full PDF bytes with `fitz.open()`, iterates pages, triages each, routes to the appropriate tier, then assembles results into a single `DoclingDocument` using a helper `_merge_pages()`.

When `settings.enable_pdf_page_router` is `False`, the method short-circuits directly to the Docling full-document conversion path — identical behaviour to `PdfStubParser` — so running tests with the flag off is a safe baseline.

### Key Implementation
```python
# parsers/pdf_router.py
import io
import logging
from io import BytesIO

import fitz  # PyMuPDF
import pymupdf4llm
from docling.document_converter import DocumentConverter
from docling.datamodel.base_models import InputFormat
from docling_core.types.doc import DoclingDocument

from config import settings
from .base import BaseParser
from .docling_parser import _build_vlm_converter  # reuse the already-tested VLM builder

logger = logging.getLogger(__name__)


class PdfPageRouter(BaseParser):
    """
    v5 PDF per-page triage router.

    Each page is independently classified as text-heavy, table-bearing, or
    image-dominant. The classification drives routing to:
      - PyMuPDF4LLM  (text-heavy pages)
      - Docling       (table-bearing pages)
      - SmolVLM       (image/diagram-heavy pages, via Docling VLM pipeline)

    Falls back to full-document Docling conversion when
    settings.enable_pdf_page_router is False.
    """

    SUPPORTED_EXTENSIONS = {".pdf"}

    def __init__(self) -> None:
        self._docling_converter: DocumentConverter | None = None
        self._vlm_converter: DocumentConverter | None = None

    def can_handle(self, ext: str) -> bool:
        return ext.lower() in self.SUPPORTED_EXTENSIONS

    # ------------------------------------------------------------------
    # BaseParser interface
    # ------------------------------------------------------------------

    def parse(self, file_bytes: bytes, filename: str, **kwargs) -> DoclingDocument:
        if not settings.enable_pdf_page_router:
            # Passthrough: identical to PdfStubParser (safe baseline)
            return self._docling_full(file_bytes, filename)

        pdf = fitz.open(stream=file_bytes, filetype="pdf")
        page_results: list[str] = []  # one markdown string per page

        for page in pdf:
            route = self._triage_page(page)
            if route == "text":
                md = pymupdf4llm.to_markdown(pdf, pages=[page.number])
                page_results.append(md)
            elif route == "table":
                md = self._docling_page(file_bytes, filename, page.number)
                page_results.append(md)
            else:  # "image"
                md = self._smolvlm_page(file_bytes, filename, page.number)
                page_results.append(md)

        pdf.close()
        return self._merge_pages(page_results, filename)

    # ------------------------------------------------------------------
    # Triage
    # ------------------------------------------------------------------

    def _triage_page(self, page: fitz.Page) -> str:
        """Classify a page as 'text', 'table', or 'image'."""
        has_table = len(page.find_tables().tables) > 0
        if has_table:
            return "table"

        has_image = len(page.get_images()) > 0
        area = page.rect.width * page.rect.height
        text_len = len(page.get_text())
        text_ratio = text_len / area if area > 0 else 0.0

        if has_image and text_ratio < settings.pdf_text_ratio_threshold:
            return "image"
        return "text"

    # ------------------------------------------------------------------
    # Per-tier extractors
    # ------------------------------------------------------------------

    def _docling_full(self, file_bytes: bytes, filename: str) -> DoclingDocument:
        """Full-document Docling conversion (fallback / stub-compatible path)."""
        from docling_core.types.io import DocumentStream
        if self._docling_converter is None:
            self._docling_converter = DocumentConverter()
        stream = DocumentStream(name=filename, stream=BytesIO(file_bytes))
        result = self._docling_converter.convert(stream)
        return result.document

    def _docling_page(self, file_bytes: bytes, filename: str, page_no: int) -> str:
        """Extract a single page via Docling and return its markdown."""
        from docling_core.types.io import DocumentStream
        if self._docling_converter is None:
            self._docling_converter = DocumentConverter()
        stream = DocumentStream(name=filename, stream=BytesIO(file_bytes))
        result = self._docling_converter.convert(stream)
        page_md = result.document.export_to_markdown()
        # TODO v5.1: scope export to single page once Docling exposes page-level export
        return page_md

    def _smolvlm_page(self, file_bytes: bytes, filename: str, page_no: int) -> str:
        """Render a page as an image and describe it with SmolVLM via Docling VLM pipeline."""
        try:
            if self._vlm_converter is None:
                self._vlm_converter = _build_vlm_converter()
            from docling_core.types.io import DocumentStream
            stream = DocumentStream(name=filename, stream=BytesIO(file_bytes))
            result = self._vlm_converter.convert(stream)
            return result.document.export_to_markdown()
        except Exception as exc:
            logger.warning("SmolVLM page %d failed for %s: %s. Falling back to PyMuPDF.", page_no, filename, exc)
            pdf = fitz.open(stream=file_bytes, filetype="pdf")
            md = pymupdf4llm.to_markdown(pdf, pages=[page_no])
            pdf.close()
            return md

    # ------------------------------------------------------------------
    # Result assembly
    # ------------------------------------------------------------------

    def _merge_pages(self, page_markdowns: list[str], filename: str) -> DoclingDocument:
        """Combine per-page markdown strings into a single DoclingDocument."""
        combined_md = "\n\n---\n\n".join(page_markdowns)
        # Use Docling's convert_string for markdown → DoclingDocument
        from docling.document_converter import DocumentConverter
        from docling.datamodel.base_models import InputFormat, DocumentStream
        converter = DocumentConverter(
            allowed_formats=[InputFormat.MD],
        )
        stream = DocumentStream(
            name=filename.replace(".pdf", ".md"),
            stream=BytesIO(combined_md.encode("utf-8")),
        )
        result = converter.convert(stream)
        return result.document
```
