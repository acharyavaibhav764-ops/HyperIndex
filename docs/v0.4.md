# Version 0.4: RESTful Routing & Endpoints

## Objective
Redesign API endpoints to follow industry-standard REST conventions, introduce versioning (`/api/v1`), modularize routes using FastAPI's `APIRouter`, unify document upload and indexing into a streamlined Ingestion endpoint, and use semantic HTTP status codes.

---

## 1. RESTful Endpoint Mapping

### Problem in v0.1
Current endpoints are verb-heavy, unversioned, multi-step, and inconsistent:
- `POST /upload`
- `POST /chunk-and-embed/{file_id}`
- `POST /generate`
- No health check endpoint

### Technical Specification
Map actions to a clean 2-core-endpoint RESTful architecture:

| v0.1 Endpoint (Legacy) | v0.4 RESTful Endpoint | Method | Status Code | Purpose |
| :--- | :--- | :--- | :--- | :--- |
| `/upload` + `/chunk-and-embed/{id}` | `/api/v1/documents` | `POST` | `201 Created` | Unified Ingestion (Upload, Parse, Chunk, Embed & Index) |
| `/generate` | `/api/v1/query` | `POST` | `200 OK` | Query RAG pipeline for an answer |
| *(None)* | `/health` | `GET` | `200 OK` | Health check for Docker / orchestrator |

*(Legacy route adapters are provided in `api/legacy.py` during v0.4.1 dual-run for backward compatibility).*

---

## 2. Router Modularization (`api/`)

Deconstruct `main.py` by grouping endpoints into dedicated router files:

```text
api/
├── __init__.py
├── dependencies.py             # Shared pipeline singletons (precursor to DI in v0.5)
├── legacy.py                   # Backward compatibility adapter for v0.1/v0.3
└── v1/
    ├── __init__.py
    ├── router.py               # Aggregates sub-routers with prefix="/api/v1"
    └── endpoints/
        ├── __init__.py
        ├── documents.py        # /api/v1/documents (Unified Ingest)
        ├── query.py            # /api/v1/query
        └── health.py           # /health
```

### `api/v1/endpoints/documents.py`
```python
from fastapi import APIRouter, File, UploadFile, status
from schemas.document import DocumentIngestResponse

router = APIRouter(prefix="/documents", tags=["Documents"])

@router.post("", status_code=status.HTTP_201_CREATED, response_model=DocumentIngestResponse)
async def ingest_documents(files: list[UploadFile] = File(...)):
    """Synchronously upload, parse, chunk, embed, and index documents."""
    ...
```

### `api/v1/endpoints/query.py`
```python
from fastapi import APIRouter
from schemas.query import QueryRequest, QueryResponse

router = APIRouter(tags=["Query"])

@router.post("/query", response_model=QueryResponse)
async def query_pipeline(request: QueryRequest):
    ...
```

### `api/v1/endpoints/health.py`
```python
from fastapi import APIRouter
from schemas.health import HealthResponse

router = APIRouter(tags=["Health"])

@router.get("/health", response_model=HealthResponse)
async def health_check():
    return HealthResponse(status="ok", version="1.0.0")
```

### `api/v1/router.py`
```python
from fastapi import APIRouter
from api.v1.endpoints import documents, health, query

api_router = APIRouter()
api_router.include_router(health.router)  # Mounted at /health
api_router.include_router(documents.router, prefix="/api/v1")
api_router.include_router(query.router, prefix="/api/v1")
```

## 3. Simplified `main.py`

With routes moved to dedicated routers, `main.py` simply mounts the aggregated router and legacy adapter:

```python
from fastapi import FastAPI
from api.v1.router import api_router
from api.legacy import legacy_router

app = FastAPI(title="Honeywell RAG", version="1.0.0", lifespan=lifespan)
app.include_router(api_router)
app.include_router(legacy_router)
```
